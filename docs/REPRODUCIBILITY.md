# 复现就绪度与运行边界

本目录的代码测试只检验**本目录自身**。未安装或运行任何第三方机器人仓库、模拟器、模型、远程脚本或付费 API。以下是阅读公开材料后整理的准备清单，不是“已经跑通”的声明。

## 不启动机器人也可以做的事

首先读取项目说明、许可证、固定版本和结果清单；其次查看少量轨迹或作者提供的报告；最后才考虑重跑。网页回放、mock 测试、保存轨迹一致性检查和新的物理 rollout 是四种不同验证。

## 复现记录必须固定什么

保存仓库 commit、模型/推理配置、benchmark 和资产版本、动作频率及单位、相机分辨率和观察时序、case / seed、成功定义、timeout、人工修正、失败次数、墙钟时间和模型调用日志。模型别名与 checkpoint 名不能代替可追溯版本。

RoboDojo 在 09-16/17 的维护更新涉及观察和 RGB 数据处理及部分资产；混用旧报告和新版本时必须说明。当前仓库 README 许可正文与 GitHub UI 标签存在不一致，本目录不替上游解释或授予许可。[S016](SOURCES.md#s016)

## 实际操作安全

先 dry-run / mock，再在隔离模拟环境中检查动作合同。真机必须由合格操作人员现场监督，有物理急停、工作空间边界、速度/力限幅、碰撞保护和安全 reset。模型输出不能绕过确定性的动作校验或保护机制。禁止把未知来源程序直接连接到运动控制器。

密钥、认证缓存、机器人地址和私有配置不进入仓库。远程 RPC、标注服务器或控制服务不要未经认证暴露到公网。首次下载大数据先核对容量与许可；解压不可信归档时拒绝绝对路径、目录穿越与指向目标目录外的链接。

模型或模拟器运行可能产生费用。此仓库的构建、校验与页面不调用模型，不启动容器/GPU，不提交集群任务，也不改变第三方资源。
