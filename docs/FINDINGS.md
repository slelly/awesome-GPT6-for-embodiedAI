# 综合结论与值得做的研究

以下事实来自链接的一手资料；“研究问题”部分是本目录的分析建议，不是已有实验结论。

## 1. 最有价值的分界是 GPT-6 在系统里做什么

GPT-Policy 使用上下文与受约束控制工具；GPT-as-Policy 比较直接动作和对 π0.5 提案的审查；ENPIRE 则提供机器人实验与策略改进框架。它们不能都简化成“把摄像头接到 GPT-6 就会控制机器人”。[S001](SOURCES.md#s001)、[S003](SOURCES.md#s003)、[S018](SOURCES.md#s018)

因此，本目录首先区分在线决策、工具/底层控制器的贡献以及离线工程工作，再看成片视频。仅凭视频通常无法判断动作是否缓存、是否暂停物理、是否经过人工修正。

## 2. 真机的简单抓放与精细操作表现差异显著

RoboCurve 报告中，方块入碗完成 19/20，而拼块完成 2/20。同一个模型在相近控制框架下表现跨度很大，不能由一个抓取视频推导通用精细操作能力。[S010](SOURCES.md#s010)

StationeryBench 五类双臂任务中，Astra 完整完成 7/100；46/100 是平均阶段进度而非 46% 成功率。与 MolmoAct2 的比较还存在控制形式、时长/步数预算、已知模型的人工评分等条件差异。这些结果可用于识别瓶颈，但不能推出“所有 VLM agent 都优于所有 VLA”。[S011](SOURCES.md#s011)、[S012](SOURCES.md#s012)

## 3. GPT + VLA 混合控制是可具体检验的方向

GPT-as-Policy 的 10 × 5 对齐案例中，Hybrid 成功率 48%，Direct 26%。报告中的 14.4% 是 GPT 修正占已执行控制步的比例，**不是模型调用、token 或费用节省百分比**。公开官方模型对照是重加权参考，不能冒充同 seed 重跑。[S003](SOURCES.md#s003)

值得检验的假设：让 VLA 保持连续运动，让 GPT 处理语义偏差、失败恢复和必要纠正，可能比全程低层 GPT 控制更合适。但仍需统一控制预算、失败定义、种子和额外人工先验做消融。

## 4. HF 轨迹比精选视频更适合做失效分析

AGP canonical 数据卡含 162 条多模型 evaluated rows；旧 YAM 数据卡还有 reset / auxiliary 等不同 session 类型，不能相加。优先研究可观察输入、工具调用、纠错记录和全程失败，而不是只统计宣传页上的成功片段。[S006](SOURCES.md#s006)、[S007](SOURCES.md#s007)、[S008](SOURCES.md#s008)

GPT-as-Policy 的 HF 发布包含对齐方法的回放入口，可先在不运行模拟器的条件下研究现有证据。数据可读不自动意味着无需额外上游资产即可复现实验。[S045](SOURCES.md#s045)

## 5. Real2Sim 至少包含两种不同目标

lingxiao-guo 的项目同时保留接触模拟、拟合和失败情况；HKU 的三视角项目包含绑定与动画插值。前者的物理接触是否有效、后者的几何与渲染是否相似，应使用不同指标。不能把“看起来与原视频一致”直接称为可训练或可迁移的物理环境。[S020](SOURCES.md#s020)、[S021](SOURCES.md#s021)

## 6. 理解类 benchmark 不替代真实控制

PhysBrain 1.5 的 28 项理解类均值将 GPT-6 列作对照，但这些分数不是机器人任务完成率。Show-Harness 提供另一种语义动作与小模型适配路径，本次未确认其 GPT-6 专项成绩；二者都保留为配套资源，而非本模型新增真机成果。[S030](SOURCES.md#s030)、[S031](SOURCES.md#s031)、[S027](SOURCES.md#s027)

## 可检验的研究问题（建议，不是结论）

| 问题 | 最小可用实验设计 | 应报告的量 |
| --- | --- | --- |
| GPT 应在何时介入 VLA？ | 固定案例，比较周期审查、置信度触发、失败触发；控制相同预算 | 成功率、恢复率、干预次数、真实耗时、token / 费用 |
| 上下文到底教会了什么？ | 仅文本、目标图、机器人示教、人类示教；打乱顺序 / 去掉动作记录 | 新任务成功率、重试数、泄露 / 人工先验依赖 |
| 视觉错误还是执行错误？ | 给定相同动作接口，分别替换感知、计划、状态反馈；保留失败轨迹 | 接触前定位误差、抓取误差、规划错误、执行误差 |
| Real2Sim 的视觉拟合能否预测控制有效性？ | 比较视频误差与新初态 rollout、接触和扰动测试 | 几何误差、接触稳定性、物理 rollout 成功率 |
| 暂停物理掩盖了什么？ | 同动作序列，分别暂停 / 不暂停；固定墙钟延迟 | 仿真秒、墙钟秒、失稳率、动作陈旧程度 |

推荐先分析公开轨迹与协议，再决定是否投入真机或大规模仿真资源。每个研究结论都应在统一协议中重新验证，不从目录中的异构数字拼接得出。
